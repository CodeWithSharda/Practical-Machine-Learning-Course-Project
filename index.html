Predicting Exercise Manner from Wearable Sensor Data

Practical Machine Learning Course Project — Rishabh Sharda

Objective

The goal of this project is to predict the classe variable from wearable accelerometer measurements collected from the belt, forearm, arm, and dumbbell of six participants performing barbell lifts. Class A represents the correct exercise execution, while classes B–E represent four different incorrect manners.

Data preprocessing

The original training data contain 19,622 observations and 160 variables. I removed metadata variables such as participant identifiers, timestamps, and window bookkeeping fields, followed by variables with very high missingness and near-zero-variance predictors. The resulting predictor set consists of direct sensor measurements expected to generalize to unseen observations.

Training strategy

I used a Random Forest classifier because the response has five classes and the sensor variables may have nonlinear and correlated relationships. The labelled data were split into a 70% development sample and a 30% untouched validation sample using stratified sampling.

Within the development sample, I used 3-fold cross-validation to tune the Random Forest parameter mtry. The validation set was excluded from tuning so that it could provide a more realistic estimate of out-of-sample performance.

Expected out-of-sample error

The exact validation accuracy and expected out-of-sample error are computed automatically in the accompanying R Markdown file. The out-of-sample error is calculated as:

validation_pred <- predict(rf_fit, newdata = validation)
cm <- confusionMatrix(validation_pred, validation$classe)

accuracy <- unname(cm$overall["Accuracy"])
oos_error <- 1 - accuracy

This hold-out error is preferable to training accuracy because the validation observations are not used during model fitting or cross-validation.

Model interpretation

The Random Forest uses measurements from multiple sensor locations. This is appropriate because incorrect lifting technique can alter movement of the torso, arm, forearm, and dumbbell in different ways. The R Markdown also produces a variable-importance plot for the 20 most influential predictors.

Conclusion

The project uses a cleaned set of wearable-sensor predictors, Random Forest classification, 3-fold cross-validation, and an independent validation split to estimate performance on unseen observations. The final fitted model is then used to classify the 20 official test cases.
